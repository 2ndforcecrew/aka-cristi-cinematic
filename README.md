# AKA.CRISTI — Cinematic

A standalone, static portfolio for AKA.CRISTI. This repository is intentionally separate from `aka-cristi-portfolio` and MUSE AI.

## Design
- Monochrome fashion-editorial art direction
- Responsive layout and staggered portfolio grid
- Scroll reveal, custom cursor, subtle grain, marquee and cinematic hero movement
- Reduced-motion support and no build step

## Run locally
Open `index.html` in a browser or serve this folder with any static server.

## Deploy
GitHub Actions publishes this repository to GitHub Pages on every push to `main`. In the repository, make sure Pages is set to **GitHub Actions** as the build/deployment source if GitHub prompts for it.

Portfolio images currently reference the existing public AKA.CRISTI portfolio's assets; the source repository itself is not modified.
